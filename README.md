# 🤖 Agente IA Web

Aplicação web desenvolvida em Python que integra múltiplas funcionalidades de Inteligência Artificial em uma única interface.

## 🚀 Funcionalidades

- 💬 Chat com IA
- 📄 Análise de documentos PDF e TXT
- 🖼️ Análise de imagens
- 🎨 Geração de imagens com IA
- ✏️ Edição de imagens enviadas
- 📥 Download de arquivos gerados
- 🌐 Interface web com Streamlit

## 🛠️ Tecnologias

- Python
- Streamlit
- OpenAI API
- PyPDF
- Pillow

## 💡 Objetivo

Projeto desenvolvido para portfólio, demonstrando habilidades em:

- Desenvolvimento de aplicações web
- Integração com APIs de IA
- Processamento de arquivos
- Manipulação de imagens

## ▶️ Executar localmente

```bash
pip install -r requirements.txt
